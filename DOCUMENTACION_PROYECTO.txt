════════════════════════════════════════════════════════════
  1. EL PROBLEMA A RESOLVER
════════════════════════════════════════════════════════════

La Universidad Tecnológica General Mariano Escobedo (UTE)
cuenta con un campus extenso que alberga múltiples edificios,
docencias, talleres y áreas de servicio (D1 al D8, T1 al T3),
cada uno con diferentes carreras, maestros, grupos y trámites.

Sin embargo, actualmente NO existe una herramienta digital
que permita a los alumnos, visitantes y personal:

  → Identificar visualmente dónde se ubica cada edificio
    dentro del campus de forma rápida e intuitiva.

  → Conocer qué carreras, maestros y grupos se encuentran
    en cada docencia o taller sin necesidad de preguntar
    a una persona o buscar en documentos físicos.

  → Saber cómo llegar a la universidad desde diferentes
    zonas de la ciudad (qué camión tomar, horarios, paradas,
    método de pago).

  → Diferenciar entre transporte público urbano y el
    servicio de camión escolar de paga que ofrece la propia
    universidad.

SITUACIÓN ACTUAL:
  • Los alumnos de nuevo ingreso frecuentemente se pierden
    dentro del campus o no saben a qué edificio dirigirse.
  • La información de rutas de transporte está dispersa en
    redes sociales o carteles físicos que se desactualizan.
  • No existe un punto digital central que unifique la
    información del campus para todos los usuarios.
  • La página oficial de la UTE no ofrece un mapa interactivo
    del campus ni información georeferenciada.

IMPACTO DEL PROBLEMA:
  • Pérdida de tiempo de alumnos y visitantes al buscar
    edificios y salones.
  • Desinformación sobre los trámites disponibles por área.
  • Dificultad para alumnos foráneos de llegar a la UTE
    usando transporte público.


════════════════════════════════════════════════════════════
  2. LA SOLUCIÓN – NUESTRO PROYECTO
════════════════════════════════════════════════════════════

Desarrollamos el "Mapa Universitario Interactivo UTE", una
aplicación web que centraliza toda la información del campus
en una interfaz visual moderna, accesible desde cualquier
dispositivo con internet.

¿Cómo resuelve el problema?

  ✔ MAPA INTERACTIVO DEL CAMPUS
    El usuario puede ver un mapa real de la UTE (coordenadas
    geográficas verificadas: 25.83044°N, 100.28213°O) con
    marcadores ubicados exactamente en cada edificio (D1–D8
    y T1–T3). Al hacer clic en cualquier edificio, un panel
    lateral muestra:
      - Nombre completo del edificio
      - Carreras y áreas que aloja
      - Lista de maestros destacados
      - Grupos activos en ese edificio
      - Trámites disponibles en esa área
      - Infraestructura: total de salones, laboratorios,
        aulas y salas
      - Horario de operación

  ✔ RUTAS DE TRANSPORTE (OCULTAS POR DEFECTO)
    El usuario activa las rutas desde un toggle en la barra
    lateral. Al activar, se dibujan en el mapa:
      - Ruta C4: La Unidad / Laredo / UTE (transporte
        público urbano, método de pago: efectivo o Mi Muevo)
      - Bus Escolar UTE Zona Sur (transporte de paga,
        $350/mes, solo con registro en Control Escolar)
    Al hacer clic sobre cualquier línea de ruta, aparece
    un popup con: horarios de entrada y salida, puntos
    de parada, costo y métodos de pago.

  ✔ SISTEMA DE ROLES DIFERENCIADOS
    La app maneja 4 tipos de usuario con permisos distintos:
      - Visitante: puede ver el mapa y las rutas
      - Alumno: acceso completo a la info del campus
      - Empleado: igual que alumno más acceso a su perfil
      - Administrador: todo lo anterior + panel de gestión
        + editor de rutas en mapa

  ✔ PANEL DE ADMINISTRACIÓN
    Solo accesible para administradores (personal de TI,
    directivos). Permite:
      - Ver estadísticas del campus (edificios, rutas,
        salones totales)
      - Agregar y eliminar edificios
      - Crear nuevas rutas dibujando directamente sobre
        el mapa (trazar puntos IDA y VUELTA)
      - Gestionar usuarios del sistema
      - Ver el log de actividad reciente


════════════════════════════════════════════════════════════
  3. HERRAMIENTAS Y TECNOLOGÍAS UTILIZADAS
════════════════════════════════════════════════════════════

FRONTEND (Interfaz de usuario)
  • HTML5          – Estructura de todas las páginas
  • CSS3           – Estilos modernos con variables, Flexbox
                     y Grid para diseño responsivo
  • JavaScript ES6 – Lógica de la aplicación, eventos,
                     manipulación del DOM, sistema de roles
  • Google Fonts   – Tipografía Inter para UI profesional

MAPA INTERACTIVO
  • Leaflet.js v1.9.4
                   – Biblioteca open-source para mapas web
                     interactivos. Maneja tiles, marcadores,
                     polilíneas (rutas), popups y tooltips.
  • CartoDB Voyager Tiles
                   – Capa de mapa base con calles, nombres
                     y puntos de referencia de la zona de
                     Escobedo, N.L.
  • GeoJSON        – Formato de datos para coordenadas
                     geográficas de edificios y rutas

ALMACENAMIENTO DE DATOS
  • localStorage   – Persistencia de datos en el navegador
                     (edificios y rutas editables por admin)
  • sessionStorage – Manejo de sesiones de usuario (login)

ENTORNO DE DESARROLLO
  • Visual Studio Code (VS Code) – Editor de código
  • Live Server (extensión VS Code) – Servidor local para
    pruebas en tiempo real (localhost:5500)
  • Google Chrome / Brave – Navegador para pruebas
  • Figma – Diseño de mockups y prototipos de la interfaz
  • Git / GitHub – Control de versiones del proyecto

COORDINACIÓN DEL EQUIPO
  • WhatsApp / Discord – Comunicación del equipo
  • Notion – Documentación y organización de tareas

REQUISITOS PARA EJECUTAR
  • Cualquier navegador moderno (Chrome, Firefox, Brave, Edge)
  • Extensión Live Server en VS Code (o cualquier servidor
    HTTP local)
  • Conexión a internet para cargar el mapa (Leaflet CDN)

  6. CÓMO EJECUTAR EL PROYECTO
════════════════════════════════════════════════════════════

  1. Descomprimir el archivo ZIP en tu computadora
  2. Abrir la carpeta ute_v4/ en Visual Studio Code
  3. Clic derecho sobre index.html
  4. Seleccionar "Open with Live Server"
  5. El proyecto abrirá en http://127.0.0.1:5500
  6. Ingresar con cualquiera de las credenciales de prueba
     o continuar como Visitante
